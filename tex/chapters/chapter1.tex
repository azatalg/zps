\section{What is a Pseudorandom Number Generator?}

A pseudorandom number generator (PRNG) is an algorithm that produces a sequence of numbers which approximates the properties of random numbers.

Unlike true randomness, which is based on unpredictable physical phenomena, a PRNG is entirely deterministic. This means that if the initial conditions are known, the entire sequence can be reproduced exactly.

In a more formal way, a PRNG can be defined as a sequence $(x_n)$ generated by a recurrence relation:

$$x_{n+1} = f(x_n)$$

where $f$ is a deterministic function and $x_0$ is the seed.

PRNGs are widely used in simulations, cryptography, numerical analysis, and computer science applications where random-like behavior is required.

\subsection{Key Properties of PRNGs}

In order for a pseudorandom number generator to be useful, it should satisfy several important properties:

\begin{itemize}
    \item \textbf{Determinism:} The generator always produces the same sequence from the same initial value.
    
    \item \textbf{Efficiency:} The algorithm should be fast and require minimal computational resources.
    
    \item \textbf{Statistical Randomness:} The generated sequence should pass statistical tests for randomness, meaning it should not exhibit obvious patterns.
\end{itemize}

\subsection{Seed (Initial Value)}

The seed is the starting value used by a PRNG. It determines the entire sequence of generated numbers.

Formally, the seed $x_0$ is the initial element of the state space $S$, and the generated sequence satisfies:

$$x_n \in S, \quad n \geq 0$$

If the same seed is used multiple times, the generator will produce exactly the same sequence. This property is useful for reproducibility in simulations and debugging.

Different seeds lead to different sequences, increasing variability.

\subsection{State Space}

A PRNG operates on a finite state space $S$. Since $S$ is finite and the generator is deterministic, every sequence must eventually become periodic.

\subsection{Period}

The period of a PRNG is the length of the sequence before it starts repeating.

Formally, the smallest positive integer $T$ such that:

$$x_{n+T} = x_n \quad \text{for all } n$$

is called the period of the generator.

A good generator has a very long period, making repetition practically unnoticeable in real applications.

\subsection{Uniformity (Distribution)}

Uniformity refers to how evenly the generated numbers are distributed over a given interval.

For a good PRNG, numbers should be uniformly distributed, meaning that each value (or range of values) appears with approximately the same frequency over time.

Formally, for a sequence $(x_n)$ in the interval $[0,1]$, uniformity means that for any subinterval $[a,b] \subset [0,1]$:

$$
\lim_{N \to \infty} \frac{1}{N} \#\{x_1, x_2, ..., x_N \in [a,b]\} = b - a
$$

Lack of uniformity can lead to biased results, which is particularly problematic in simulations and statistical applications.

\subsection{Summary}

A good pseudorandom number generator should produce sequences that are deterministic yet appear random, have a long period, and exhibit uniform distribution. These properties ensure that the generator can be reliably used in practical applications.

Many practical PRNGs, such as linear congruential generators or LFSR, are based on specific choices of the function $f$ and the structure of the state space.
